PREPORA — CLEAN MINIMAL UI/UX RESTRUCTURE
=========================================

The current PREPORA website feels visually overloaded.

DO NOT remove important functionality.

The problem is INFORMATION DENSITY and POOR HIERARCHY,
not lack of features.

Refactor the UI so PREPORA feels:

- Premium
- Clean
- Simple
- Academic
- Modern
- Calm
- Professional
- Easy to understand

IMPORTANT:

Keep all existing business logic and features.

Do NOT delete features.

Instead, reorganize and progressively reveal them.

=========================================
CORE RULE
=========================================

ONE PAGE = ONE PRIMARY PURPOSE.

Every page must have:

1. Clear page title
2. Short supporting description if necessary
3. One primary action
4. Only the information required for that page
5. Secondary information lower on the page or behind interaction

Avoid showing every feature at once.

=========================================
REMOVE VISUAL OVERLOAD
=========================================

Audit every page.

Remove/reduce:

- Unnecessary cards
- Repeated information
- Long descriptions
- Duplicate statistics
- Excessive badges
- Excessive buttons
- Decorative sections
- Repeated headings
- Large empty explanations
- Too many charts
- Too many simultaneous recommendations
- Excessive shadows
- Excessive borders
- Excessive containers

Do NOT create a card for every small piece of information.

Use typography, spacing and grouping instead.

Do not create huge empty spaces either.

=========================================
COLORS
=========================================

Keep PREPORA's monochrome direction.

Primary:

White
Gray

Use semantic colors only when needed:

Amber = warning
Red = error

Purple-heavy UI
Neon colors
Rainbow dashboards
Excessive gradients
Gaming aesthetics

=========================================

=========================================

Mobile must feel even simpler.

At:

360px
375px
390px
412px

Prioritize:

Essential information

Convert complex tables into cards.

Use collapsible sections where necessary.

=========================================
DESKTOP
=========================================

Desktop can use more horizontal space,
but should NOT become a dashboard wall.

Use:

Main content
+
small supporting sidebar

when useful.

Do not fill every empty pixel.

White space is intentional.

=========================================
ANIMATION
=========================================

Use subtle animation only.

150–250ms.

No excessive:

- Parallax
- Floating cards
- Bouncing elements
- Continuous animations
- Decorative motion

Animation should communicate state,
not distract from studying.

=========================================
CONTENT DENSITY AUDIT
=========================================

For EVERY page ask:

1. What is the main purpose?
2. What does the user need immediately?
3. What can be hidden until requested?
4. What information is duplicated?
5. Which cards can be merged?
6. Which statistics belong on another page?
7. Which buttons are secondary?

Reduce density without removing functionality.

=========================================
IMPORTANT PRODUCT PRINCIPLE
=========================================

PREPORA has many powerful features.

That does NOT mean every feature should be visible simultaneously.

The website should feel:

SIMPLE ON THE SURFACE
POWERFUL UNDERNEATH

A new student should understand the page immediately.

An advanced student should be able to access deeper tools when needed.
